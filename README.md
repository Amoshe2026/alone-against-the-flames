# 向火独行 · Alone Against the Flames

《克苏鲁的呼唤》第七版入门套装单人互动冒险的网页版实现。单文件、零依赖，双击 `index.html` 即可游玩。

**在线游玩**：https://amoshe2026.github.io/alone-against-the-flames/

---

## 玩法

打开页面后先选择开局模式：

- **经典模式**：完整走一遍调查员创建流程（属性池分配、职业、技能点、兴趣点、派生属性），系统会给出每一步的规则说明。支持部分一键随机与整卡一键随机。
- **故事模式**：跳过车卡，直接进入故事。遇到检定时自行选择判定成功或失败，专注体验分支剧情。

车卡完成后可以导出人物卡，下次游玩时导入继续；也可以保留在当前浏览器中。

## 特性

- 原著 270 个编号条目完整还原，含 54 个特殊节点（车卡、检定、战斗、理智损失等）
- 符合 CoC 7e 规则的判定系统：技能检定、奖励/惩罚骰、成功等级（常规/困难/极难/大成功/大失败）、对抗检定
- 支持对判定结果改判，改判链完整可回退
- 三种正文字体切换（宋体 / 楷体 / 思源宋体），规则性说明文字单独分层显示
- 左侧栏实时显示人物卡草稿、技能与行程记录
- 自适应布局，桌面与移动端均可读

## 技术说明

单个 HTML 文件，内联全部 CSS/JS/文本数据，无外部请求、无构建运行时依赖。存档使用浏览器 localStorage。
